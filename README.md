## Tech Stack
- **ML:** Python, TensorFlow/Keras, MobileNet (Transfer Learning), PlantVillage Dataset, Google Colab
- **Backend:** Python, FastAPI, Uvicorn
- **Frontend:** React.js / Flutter
- **Design:** Figma
- **Data:** JSON/CSV, Google Translate API
- **Deployment:** Git/GitHub, Docker, Render/Vercel
- **Scaling:** OpenWeatherMap API, Twilio (SMS/IVR)

## Folder Structure
```
smart-crop-advisory-system/
├── ml/          → model training code, Colab notebooks, exported model files
├── backend/     → FastAPI server, API endpoints
├── frontend/    → React or Flutter app
├── design/      → Figma exports, icons, design specs
├── data/        → disease-remedy dataset, translations
├── docs/        → roadmap, setup guide, presentation script, meeting notes
└── README.md    → this file
```
